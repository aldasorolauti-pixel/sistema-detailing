# Detailing Booking System

Sistema de reservas para servicios de detailing automotriz construido con React 18, Vite y Tailwind CSS.

## 🚀 Características

- ✨ Interfaz moderna y responsiva
- 🌙 Modo oscuro con persistencia
- 📱 Diseño mobile-first
- 🎨 Tailwind CSS con tema personalizado
- 🔧 Componentes reutilizables
- ⚡ Vite para desarrollo rápido

## 🛠️ Tecnologías

- **React 18** - Framework UI
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Lucide React** - Iconos

## 📦 Instalación

```bash
npm install
```

## 🏃 Desarrollo

```bash
npm run dev
```

## 🏗️ Build

```bash
npm run build
```

## 👀 Preview

```bash
npm run preview
```

## 📁 Estructura del Proyecto

```
src/
├── components/
│   ├── ui/           # Componentes UI reutilizables
│   ├── booking/      # Componentes de reservas
│   └── layout/       # Componentes de layout
├── hooks/            # Custom hooks
├── utils/            # Funciones utilitarias
├── lib/              # Constantes y configuración
└── App.jsx           # Componente principal
```

## 🎨 Tema

- **Color Primary**: #F59E0B (Amarillo)
- **Color Secondary**: #1F2937 (Gris oscuro)
- **Dark Mode**: Habilitado
